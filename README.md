# Terrain Battle: Edge Wars — Gizlilik Politikası / Privacy Policy

Bu depo **yalnızca** Android oyunu *Terrain Battle: Edge Wars* için gizlilik
politikası sayfasını barındırır. Google Play, mağaza listelemesinde herkese
açık bir gizlilik politikası URL'si istediği için bu depo public'tir.

**Oyunun kaynak kodu bu depoda DEĞİLDİR** ve public değildir.

This repository hosts **only** the privacy policy page for the Android game
*Terrain Battle: Edge Wars*. It is public because Google Play requires a
publicly reachable privacy policy URL for the store listing.

**The game's source code is NOT in this repository** and is not public.

---

## İçerik / Contents

- `index.html` — gizlilik politikası, Türkçe ve İngilizce (tek sayfa, harici
  kaynak kullanmaz).

## Yayın / Publishing

GitHub Pages ile `main` dalının kökünden yayımlanır.

Politika metninin kaynağı, oyunun (private) deposundaki
`docs/PRIVACY_POLICY.md` dosyasıdır; burada değişiklik yapılacaksa iki yer de
güncellenmelidir.
